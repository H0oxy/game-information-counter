# [Game Information Counter](https://www.nexusmods.com/eldenring/mods/10658)

HUD статистики Elden Ring для стримов: боссы X/Y, смерти, уровень, руны, время
игры, NG+, а в бою с боссом — счётчик смертей на нём и секундомер боя. Ещё
несколько строк по умолчанию выключены: % исследованной карты, темп убийств,
смертей в час, средняя цена босса, «смертей от зрителей».

Вторая половина мода — интерактив: зритель тратит баллы канала Twitch, и в игре
нажимается клавиша, спавнится враг или срабатывает эффект. См. раздел ниже.

Два вывода статистики работают одновременно, любой можно выключить:

- **оверлей** поверх игры;
- **веб-страница** для OBS Browser Source (`http://127.0.0.1:7777/hud`), с
  прозрачным фоном.

## Чем отличается от других счётчиков боссов

Число боссов не зашито в мод — оно читается из самой игры. Каждая строка
`GameAreaParam` это босс со своим флагом победы, а мод, добавляющий боссов
(Convergence, Reforged и т.п.), добавляет строки в этот же парам. Поэтому
знаменатель растёт сам, без обновления мода.

## Установка

Нужен загрузчик DLL-модов, который уже отключает EAC, — сам мод в это не лезет.
Достаточно одного из трёх, регистрировать **только в одном**: второй загрузчик
запустит вторую копию оверлея поверх первой.

- **Elden Mod Loader** — положить `game_information_counter.dll` в его папку `mods/`.
- **ModEngine2** — положить в `mods/` и дописать в `config_eldenring.toml`:
  ```toml
  external_dlls = ["mods\\game_information_counter.dll"]
  ```
- **ModEngine3** — в профиль `.me3`:
  ```toml
  [[natives]]
  path = 'game_information_counter.dll'
  ```

При первом запуске рядом с DLL появятся `game_information_counter.ini` со
всеми настройками и папка `locale` с переводами интерфейса.

## Настройка

Настройки открываются по **F7** прямо в игре — изменения применяются и
сохраняются сразу.

Можно и руками: правишь `game_information_counter.ini` — применится при следующем запуске
игры. Отдельной клавиши перечитывания больше нет: всё, ради чего она была
нужна, настраивается прямо в окне.

F7, а не F5: последнюю часто занимают другие моды, и рядом с таким клавиша
срабатывала бы в двух окнах сразу.

Окно поделено на вкладки: **Панель**, **OBS**, **Twitch**, **Награды**,
**Прочее**. Наверху — поиск по настройкам.

Полный список ключей с комментариями лежит в самом `game_information_counter.ini`.
Коротко:

| Ключ | Что делает |
|---|---|
| `overlay_enabled`, `web_enabled`, `web_port` | Какие выводы включены и на каком порту веб |
| `show_*` | Каждая строка HUD включается/выключается отдельно; `show_map_explored`, `show_deaths_on_boss`, `show_viewer_kills`, `show_boss_kill_rate`, `show_death_rate`, `show_avg_attempts` по умолчанию выключены |
| `boss_count` | `all` (по умолчанию) — все строки `GameAreaParam`, с мини-боссами и повторками; `named` — только именованные. Оба числа читаются из игры |
| `panel_x`, `panel_y`, `panel_opacity`, `ui_scale` | Положение и вид панели |
| `hide_in_cutscene`, `hide_in_menu` | Прятать HUD в катсценах и в игровом меню |
| `accent_color`, `label_color`, `value_color` | Цвета, `RRGGBB` или `RRGGBBAA` |
| `font_path`, `label_size`, `value_size`, `counter_size` | Шрифт и кегли |
| `panel_style`, `web_panel_style` | Рамка панели и виджета: `frame`, `bare`, `bar`, `bar_right` |
| `panel_rounding`, `border_width` | Скругление углов и толщина золотой линии (у виджета — `web_*`) |
| `toast_*`, `web_toast_*` | Вид карточки покупки зрителя: своя рамка, размеры, положение |
| `twitch_*`, `spawn_*`, `enemy_tag_*`, `viewer_*` | Интерактив: подключение, спавн врагов, никнеймы над врагами — секции `[twitch]`, `[spawn]`, `[nicknames]` в `.ini` |
| `settings_key`, `boss_list_key` | Клавиши окна настроек (F7) и списка боссов (F8) |
| `lang` | Язык интерфейса: `auto` или имя файла из папки `locale` |

## Язык и свой перевод

Весь текст интерфейса лежит в папке `locale` рядом с DLL - по файлу на язык,
имя файла и есть код языка. В комплекте `ru.ini` и `en.ini`.

Чтобы добавить свой язык, скопируй `en.ini` в файл со своим кодом и переведи
правую половину строк:

```ini
; locale/pl.ini
_name  = Polski
_steam = polish

Deaths = Zgony
Level  = Poziom
```

- слева от `=` - английский текст из мода, это ключ, его менять нельзя;
- `_name` - как язык подписан в настройках, `_steam` - что для него возвращает
  Steam (по нему работает `lang = auto`);
- хвост `##` в ключе (`Deaths##fight`) отличает две одинаковые английские
  строки друг от друга и на экран не идёт;
- строки, для которых перевода нет, показываются по-английски.

Файл подхватывается при запуске игры: в F7 -> Прочее появляется ещё одна
кнопка выбора языка. Тот же язык получает и виджет в OBS.

Шрифт печётся ровно под те буквы, которые есть в файле, так что польский,
турецкий и прочая латиница работают сразу. Для иероглифов нужен ещё и шрифт с
ними - путь задаётся ключом `font_path`.

## Twitch: зрители платят — в игре что-то происходит

Необязательная половина мода. Зритель тратит баллы канала, мод исполняет
привязанное действие. Награды заводит стример — на дашборде Twitch либо прямо в
**F7 → Награды**, — мод только слушает.

Три вида действий на награду:

- **клавиша** — нажать коротко или подержать N секунд (бег, перекат, прыжок,
  использование предмета);
- **спавн врага** — из списка ~200 проверенных существ, каждое со ступенью
  сложности I–IV; появляется перед камерой, не в стене и не над обрывом, живёт
  заданное время. «Случайный враг» разыгрывается в момент покупки;
- **эффект** — полное лечение, мана, 1 HP, вылечить или раздуть босса, урезать
  или отнять выносливость, замедлить или ускорить игру, качка обзора, забрать
  фляги, +3 заряда фляги, рунический обмен (наносишь урон — капают руны,
  получаешь — списываются дороже).

Сверх этого:

- **никнеймы зрителей над врагами** — из анонимного чата, без авторизации,
  достаточно имени канала. Под ником можно показывать последнюю реплику зрителя;
- **имена боссов** над их головой;
- **карточки покупок** — поверх игры и отдельным источником OBS `/toasts`; не
  гаснут в меню и катсценах, потому что за них заплачено;
- **возврат баллов** — за покупку сверх лимита очереди, в кулдауне, в бою с
  боссом, в Крепости Круглого стола, при обрыве связи;
- **кулдауны** на зрителя (свой для клавиш, спавна и эффектов) и на награду,
  лимит очереди, лимит врагов в мире и одинаковых врагов.

Подключение — device code flow: Client Type = **Public**, Client Secret не
нужен и нигде не хранится. Client ID и токен на диске шифруются DPAPI под
учётную запись Windows — на другой машине файлы нечитаемы.

Баллы канала есть только у **Affiliate и Partner**. На обычном канале зрителям
покупать нечем, но свою награду стример гасит и проверяет сам (F7 → Награды →
«Проверить», F7 → Twitch → «Тестовая покупка»).

Проверить сеть, не заходя в игру:

```
cargo run --example twitch_check -- <client_id>            # авторизация с нуля
cargo run --example twitch_probe -- <путь\к\.twitch>       # по уже выданному токену
```

## Список боссов (F8)

Отдельное окно: кто из боссов ещё жив, в какой он локации и как далеко до него,
с фильтрами «рядом» и «воспоминания». Список строится из парамов игры и таблицы
`src/boss_names.txt` — боссы DLC в ней есть наравне с ванильными, ждать встречи
с ними не нужно. Имена боссов из модов (Convergence и т.п.) подхватываются при
встрече и запоминаются в `game_information_counter.bosses`.

Окно не попадает ни на панель, ни в OBS — оно для самого стримера.

## Статистика переживает перезаход

Попытки на боссах, время боя, смерти на каждом боссе, стрик без смертей и
счётчик «смертей от зрителей» нигде в сейве игры не хранятся — мод копит их сам
в файле `game_information_counter.stats` рядом с DLL. Без него они
обнулялись бы при каждом перезапуске игры.

Файл разбит на секции по имени персонажа, так что второй персонаж не портит
статистику первого:

```
[Тарнишед]
last_death = 1755450000
attempt = 167968768|100,200|17|9|253.4|0|Margit, the Fell Omen
```

Поля попытки: блок карты, FMG id (несколько — если босс менял имя между фазами),
номер попытки, счётчик смертей на момент первой встречи, длительность последнего
боя в секундах, шёл ли бой ещё в момент сохранения (`1`/`0`), имя. Строки старого
формата, без предпоследнего поля, читаются как раньше.

Пишется не чаще раза в 3 секунды и через временный файл, так что вылет игры не
оставит обрезанный. Читается человеком и правится руками, если очень надо.

Рядом с DLL мод держит и другие свои файлы:

- `game_information_counter.bosses` — имена боссов, выученные в бою
  (`флаг = имя`), для списка по F8;
- `game_information_counter.twitch` — токен Twitch, шифрованный;
  **не выкладывать**;
- `game_information_counter.rewards` — какая награда канала к какому
  действию привязана.

Всё остальное — смерти, уровень, руны, время игры, NG+ и список убитых боссов —
хранит сама игра, мод их только читает.

Два персонажа с одинаковым именем делят одну секцию: различить их нечем.

## OBS

**Browser Source** — самый удобный вариант: HUD виден только зрителям, не
закрывает игру, свободно двигается по сцене.

Веб-вывод по умолчанию выключен — включить в F7 → OBS («Включить виджет») или
ключом `web_enabled = true`.

Два отдельных источника — их двигают по сцене независимо друг от друга
(порт из `web_port`):

| URL | Что показывает |
|---|---|
| `http://127.0.0.1:7777/hud` | Статистика |
| `http://127.0.0.1:7777/toasts` | Покупки зрителей |

Фон страницы прозрачный, ничего дополнительно включать не нужно.

**Game Capture** (для оверлея внутри игры) — в свойствах источника включить
галку **«Захватывать сторонние оверлеи (как у Discord)»**. Без неё оверлей
виден в игре, но не попадает в запись.

## Игра обновилась

Мод продолжает работать: после патча игры он **не закрывает её и не выключается
сам**. Раньше незнакомая версия означала мгновенный вылет игры при запуске.

Почти всё мод находит по именам классов, а не по адресам, поэтому патч игры на
это не влияет. По адресам идёт немногое, и на версии, для которой адреса ещё не
сняты, пустыми останутся: **смерти**, **время игры**, **NG+** и **признак боя с
боссом**; спавн врага откажется искать пол и скажет об этом. Уровень, руны, имя,
карта, боссы и подписи работают как обычно.

Адреса обновляются по инструкции в `vendor/README.md`.

## Сборка

```
cargo build --release
```

Результат — `target/release/game_information_counter.dll`. Нужен toolchain
`x86_64-pc-windows-msvc` и MSVC Build Tools.

`cargo test` гоняет ту логику, которую можно проверить без игры: разбор `.ini`,
сборку JSON, форматирование чисел, счётчик попыток на боссе и сохранение
статистики. Всё, что трогает живую память, проверяется только запуском игры.

## Антивирусы ругаются - почему

На VirusTotal у DLL несколько срабатываний, и все они generic/ML: ни один
вендор не назвал семейство. Причина - набор системных вызовов, который в моде
нужен по делу, а по отдельности встречается в малвари:

- три детура user32 - глушат игровой ввод, пока открыто окно настроек;
- `SendInput` и `GetAsyncKeyState` - купленная зрителем награда нажимает
  клавишу, а проверка нужна, чтобы не отобрать клавишу у игрока;
- чтение буфера обмена - Ctrl+V в окне настроек (ImGui своего не даёт);
- сеть к api.twitch.tv и HTTP-сервер на 127.0.0.1 - интеграция с Twitch и
  страница для OBS. Обе по умолчанию выключены;
- DPAPI - шифрует твой OAuth-токен на диске, чтобы он не лежал открытым.

Чего в моде нет: инжекта в чужие процессы, анти-отладки, упаковщика,
обфускации, автозапуска. Исходники здесь целиком, сборка идёт в GitHub Actions.

DLL из релиза можно сверить с этим репозиторием:

```
gh attestation verify game_information_counter.dll --repo H0oxy/game-information-counter
```

Шаблон обращения к вендорам, если файл заблокировали, -
[docs/av-false-positive.md](docs/av-false-positive.md).
